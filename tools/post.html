the post office

connect your post office (Supabase)

  1. On supabase.com, open your project, then SQL Editor → New query. Paste everything from tools/supabase-setup.sql and press Run (once).
  2. In Project Settings → Data API (or API), copy the Project URL.
  3. In Project Settings → API Keys, copy the secret key (sb_secret_…). It stays on this computer only (in the private .inbox folder), never on the site.

the site itself also needs the Project URL and the publishable key (sb_publishable_…): those go in SUPABASE near the top of sky/sky.js.

in the living space (content/living/bottles/): pin one to the board, put it on the pile of letters, or leave it in the crate for anyone to uncork. deleting one also takes it off the board and the pile.

visitors' art on your site

in the portfolio in the workshop (content/workshop/visitors/). hang one in a frame with its number: the living space, the workshop or the hall of shame (click it again to take it down). “move to the walls pool” takes it out of the portfolio but keeps it for the frames.
